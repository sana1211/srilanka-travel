# 🇱🇰 Sri Lanka Travel Website

A modern, responsive, and visually immersive travel website designed to showcase the beauty, culture, heritage, wildlife, and unforgettable experiences of Sri Lanka.

The platform allows visitors to explore destinations, discover curated travel packages, browse a visual gallery, view interactive itineraries, check travel essentials, estimate journey costs, and plan a personalized Sri Lankan adventure.

---

## ✨ About the Project

**Sri Lanka Travel Website** is a premium travel experience built around the idea of introducing visitors to the heart and soul of Sri Lanka.

From ancient kingdoms and misty highlands to wildlife safaris and golden coastlines, the website provides an engaging digital journey across the island.

> Welcome to the Heart of Sri Lanka.

## 📸 Visual Gallery

The gallery presents Sri Lanka through several travel categories:

- Ancient Heritage
- Highlands & Tea
- Wildlife & Nature
- Golden Coasts
- City & Culture

Users can open each image in an interactive lightbox to view:

- Destination name
- Location
- Image description
- Photographer credit
- Embedded Google Map
- Direct Google Maps access
